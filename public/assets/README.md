# El Cuento · Asset Placement Directory

Place all of your high-resolution render images, floor plans, and site maps inside this folder.
When hosted on platforms like **Vercel**, everything inside this folder will be served statically from the root path `/assets/`.

## File Naming Conventions

To ensure the showcase site automatically matches and displays corresponding files for specific residential villas, name your files according to the definitions below:

### 1. Architectural Floor Plans
To replace default high-performance fallback vectors with your final floor-plans, drop `webp` or `jpg` images matches the standard paths mapped inside the apartments schema:
- **Block A Garden Suite (A-01)**: `floorplan_a01.webp` or `floorplan_a01.jpg`
- **Block A Terrace Studio (A-02)**: `floorplan_a02.webp` or `floorplan_a02.jpg`
- **Block A Eastern Studio (A-03)**: `floorplan_a03.webp` or `floorplan_a03.jpg`
- **Block A Garden Suite (A-04)**: `floorplan_a04.webp` or `floorplan_a04.jpg`
- **Block B Sky Penthouse (B-01)**: `floorplan_b01.webp` or `floorplan_b01.jpg`
- **Block B Sky Penthouse (B-02)**: `floorplan_b02.webp` or `floorplan_b02.jpg`
- **Block C Pool View Estate (C-02)**: `floorplan_c02.webp` or `floorplan_c02.jpg`
- **Block C Pool View Estate (C-03)**: `floorplan_c03.webp` or `floorplan_c03.jpg`
- **Block C Pool Front Pavilion (C)**: `floorplan_c.webp` or `floorplan_c.jpg`

### 2. Live Site Master Plan Overlay (Optional)
If you have a textured site map render, you can replace the dynamic interactive vector overlay layer or add high-contrast textures.
Alternatively, the high-fidelity interactive vector site map built into the app can remain running, as it binds to coordinate clicks beautifully.
